
# StudyFlow

A simple Flask + HTML/CSS/JavaScript study planner for students.

## Run locally

1. Create a virtual environment:
   `python -m venv .venv`
2. Activate it.
3. Install Flask:
   `pip install flask`
4. Start:
   `python app.py`
5. Open `http://127.0.0.1:5000`

## Included
- Study goal, days, and minutes/day inputs
- Realistic day-by-day plan
- Lighter review days and a rest day on longer plans
- Task completion checkboxes
- Encouragement modal + emoji after completing tasks
- Day/week/month study-hour dashboard
- Topics completed and overall progress
- Light/dark mode
- LocalStorage persistence for progress/theme
